## Reporting a Vulnerability

If you discover a suspected security vulnerability in Content Engine Pro, please report it **responsibly and privately**.

> [!CAUTION]
> **DO NOT file public GitHub issues for security vulnerabilities.**
> Public disclosure before a fix is published places user websites at risk.

### How to Submit a Report:
1. Send an email to **[security@code-elta6ur.net](mailto:security@code-elta6ur.net)**.
2. Provide a clear description of the vulnerability type (e.g., XSS, CSRF, Privilege Escalation, SQL Injection).
3. Include step-by-step reproduction instructions or a minimal proof of concept.
4. Specify your environment details (WordPress version, PHP version, active plugins).

### Our Security Response Commitment:
* **Initial Acknowledgment**: Within **48 hours** of report receipt.
* **Triage & Assessment**: Technical assessment and validation within **5 business days**.
* **Remediation & Patch**: Coordination of a verified security patch and release advisory.
* **Credit & Recognition**: Responsible security researchers will be acknowledged in release notes upon publication of the fix (unless anonymity is requested).
