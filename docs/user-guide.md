# Admin User Guide — Content Engine Pro

This guide provides a comprehensive walkthrough of every screen, setting, and workflow available within the WordPress admin dashboard for **Content Engine Pro**.

---

## 1. Dashboard Overview (`cta-ce-dashboard`)

The **Dashboard** serves as your central control room:

* **Key Performance Metrics**:
  * **Total Articles Generated**: Cumulative count of all content created by the engine.
  * **Active Schedules**: Number of running automated cron rules.
  * **Pending Queue Items**: Jobs currently waiting in the background execution pipeline.
  * **Active Providers**: Overview of currently configured and reachable AI endpoints.
* **Quick Generation Hub**: A streamlined prompt box to initiate immediate single-article generation without leaving the dashboard.
* **License & System Health Status**: Real-time indicator displaying subscription status, active plan, days until renewal, and WP-Cron health.

---

## 2. Article Generator (`cta-ce-generate`)

The **Create Article** screen orchestrates the multi-stage generation engine:

### Generation Parameters:
* **Topic / Keyword**: Enter the subject of the article. Be as descriptive as desired.
* **Content Type**:
  * *Standard Article*: Balanced editorial structure for general blog topics.
  * *Technical Tutorial*: Step-by-step guides with code blocks and prerequisite checklists.
  * *Course Lesson*: Modular chapter structured for educational progressions.
* **Target Word Count**: Select or input your target length:
  * Free Plan: Capped at 700 words.
  * Pro Plan: Supports 1,500, 2,500, 4,000, and up to 6,000 words.
* **Language**: Choose between **العربية (Arabic)** and **English**.
* **Tone**: Professional, Authoritative, Conversational, Academic, or Inspiring.
* **Target Audience**: Defines the technical depth and assumed reader knowledge.
* **Custom Research Notes**: Enter specific bullet points, proprietary facts, statistics, or mandatory brand constraints to be woven into the content.
* **Provider Selection**: Choose a specific AI provider, or select **Auto (Priority Fallback)** to let the system route the request through your prioritized provider list.

### Interactive Generation Pipeline:
When you click **Start Intelligent Generation**, the screen opens a real-time progress monitor:
1. `cta_ce_generate_outline`: Computes the optimal section count and writes a detailed outline.
2. `cta_ce_generate_section`: Iteratively writes each section, supplying the summary of previous sections to ensure unbroken narrative flow.
3. `cta_ce_assemble_article`: Assembles the Gutenberg blocks locally in PHP, validates word counts, injects internal links, and generates SEO schema.
4. `cta_ce_save_article`: Inserts the post as a WordPress draft (`wp_posts`) and stores a version snapshot in `wp_cta_ce_history`.

## 3. Generated Articles Catalog (`cta-ce-articles`)

A dedicated management view for all posts generated by the engine:

* **Table Columns**:
  * **Article Title**: Direct link to the WordPress Gutenberg editor.
  * **Actual Word Count**: Calculated real words (excluding HTML markup and comments).
  * **AI Provider Used**: Identifies which provider generated the text (e.g., Gemini, Groq).
  * **Publication Status**: Draft, Pending Review, or Published.
  * **Associated Series**: Displays course name and lesson number if part of a series.
  * **Date Created**: Localized timestamp.
* **Revision History Access**: Open historical snapshots to restore earlier versions of generated content.

---

## 4. Content Series & Course Engine (`cta-ce-series`)

Dedicated interface for creating structured, multi-part curriculum series (`cat_series`):

* **Create New Series**:
  1. Enter the overarching course topic (e.g., *"Modern Cloud Architecture with Docker and Kubernetes"*).
  2. Specify the total number of lessons (e.g., 8 lessons).
  3. Click **Generate Syllabus with AI**.
* **Interactive Curriculum Editor**:
  * Edit individual lesson titles and descriptions.
  * Reorder lessons using drag-and-drop handles.
  * Add custom notes to specific lessons to guide generation.
* **Scheduling and Batch Enqueueing**:
  * Choose whether to enqueue all lessons immediately as drafts, or distribute them across a recurring weekly cadence (e.g., every Tuesday and Friday).
  * Lessons are generated with cross-lesson context awareness to eliminate conceptual repetition.

---

## 5. Schedules & Recurring Rules (`cta-ce-schedules`)

Automate continuous content publishing without manual intervention:

* **Rule Parameters**:
  * **Schedule Name**: Descriptive label for the rule.
  * **Target Category**: Standard WordPress category where generated posts will be assigned.
  * **Days of the Week**: Multi-select check boxes (Saturday through Friday).
  * **Publishing Times**: Comma-separated 24-hour time slots (e.g., `08:00, 14:00, 20:00`).
  * **Target Word Count**: Desired length for articles created under this schedule.
  * **Content Type & Language**: Default editorial presets.
* **Execution Logic**: The minutely WP-Cron worker monitors your site's local timezone. When a scheduled time slot arrives, the engine enqueues an article job in `wp_cta_ce_queue`.

---

## 6. Publishing Calendar (`cta-ce-calendar`)

A visual monthly editorial calendar:

* Displays scheduled, pending, and completed articles mapped to specific dates.
* Color-coded status badges:
  * Green: Completed & Published / Drafted.
  * Blue: Pending in Queue.
  * Orange: Retry in Progress.
* Navigate backward and forward across calendar months with dynamic AJAX loading (`cta_ce_get_calendar_events`).

---

## 7. Background Task Queue (`cta-ce-queue`)

Inspect and manage background jobs currently executing or scheduled:

* **Queue Columns**:
  * **ID**: Unique database task identifier.
  * **Task Type**: `single`, `series_lesson`, or `outline`.
  * **Title**: Target topic.
  * **Status**: `pending`, `processing`, `retry`, `completed`, or `failed`.
  * **Attempts**: Current attempt vs. maximum attempts (default: 3).
  * **Locked Provider**: Provider bound to the job to ensure stylistic consistency.
  * **Scheduled Time**: Localized execution timestamp.
  * **Error Message**: Diagnostic details if a previous attempt failed.
* **Queue Actions**:
  * **Run Now**: Manually trigger immediate execution of a pending or retry job.
  * **Retry Job**: Reset an exhausted failed job back to pending.
  * **Delete**: Remove a job from the queue.
  * **Purge Completed**: Clean all successfully finished tasks.

## 8. AI Provider Configuration (`cta-ce-providers`)

Configure your inference connections:

* **Provider Cards**:
  * **Google Gemini**: Input Google AI Studio API key, select Flash or Pro model, set temperature (default: `0.7`).
  * **Groq Cloud**: Input Groq API key, select Llama 3.3 model.
  * **OpenRouter**: Input OpenRouter key to access diverse open-source models.
  * **Mistral AI**: Input Mistral API key.
  * **Cerebras Cloud**: Input Cerebras key for high-throughput inference.
  * **Custom / Local (Ollama)**: Input local base URL (default: `http://localhost:11434/v1/chat/completions`) and model name.
* **Testing & Model Discovery**:
  * **Test Connection**: Verifies outbound HTTPS connectivity and latency.
  * **Discover Models**: Queries the provider's API to fetch the latest available models.
* **Priority Sequence**: Drag-and-drop the provider cards to establish your preferred automatic fallback sequence.

---

## 9. Prompt Templates (`cta-ce-templates`)

Customize system instructions to match your brand voice:

* **Pre-Loaded Templates**:
  * **General Article**: Structured for balanced, comprehensive blog posts.
  * **Technical Tutorial**: Formatted for code snippets, prerequisites, and developer clarity.
  * **Course Lesson**: Optimized for pedagogical flow and actionable takeaways.
* **Customization Controls**: Edit system instructions, default structure guidelines, and tone adjectives. Custom templates persist across plugin updates.

---

## 10. General Settings (`cta-ce-settings`)

System-wide operational controls:

* **Default Language**: Choose primary language (`ar` or `en`).
* **Default Post Status**: Set new articles to `draft` (recommended) or `publish`.
* **Batch Processing Limit**: Number of queue items processed per cron minute (default: 2, range: 1–5).
* **Retry Backoff Delays**: Configurable intervals for Attempt 1 (default: 5m), Attempt 2 (default: 15m), and Attempt 3 (default: 30m).
* **Automated Internal Linking**: Enable or disable automatic internal link injection, and set maximum links per post (default: 5).
* **Automated FAQ Schema**: Toggle JSON-LD structured data output.
* **Data Cleanup on Uninstall**: Choose whether to delete custom database tables and options if the plugin is uninstalled.
* **Export / Import**: One-click download or upload of complete plugin configuration in sanitized JSON format.

---

## 11. Commercial Licensing (`cta-ce-license`)

Manage your Pro subscription:

* **License Key Activation**: Enter key and activate.
* **Live Subscription Details**: Displays active plan, activation token, registered domain, and expiration date.
* **One-Click Deactivation**: Safely deactivates your key to allow immediate migration to another domain.
* **Manual Refresh**: Forces an instant status sync with the licensing server.

---

## 12. Operation Logs & Diagnostics (`cta-ce-logs` & `cta-ce-about`)

* **Event Logs (`cta-ce-logs`)**: Real-time audit log of all generations, API calls, HTTP status codes, token usage, and errors. All API keys and authorization tokens are automatically redacted.
* **About & Diagnostics (`cta-ce-about`)**: Displays server environment metrics (PHP version, MySQL version, active extensions, memory limit, max execution time, and cron status).
